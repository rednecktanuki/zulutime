# 🕐 Zulu Time & Julian Date Display

**A simple, accurate Zulu (UTC) time display for radio operators.**
https://rednecktanuki.github.io/zulutime/

---

## 📡 Why This Was Made

This tool was created for **radio programming and frequency management** where **precise Zulu time** is essential.

### 🎯 For 25u (25 kHz) Radio Programming

When programming radios with **25 kHz channel spacing** (25u), accurate time coordination is critical because:

- **Frequency schedules** often rely on exact UTC time for frequency changes
- **Net schedules** require operators to be on frequency at precise Zulu times
- **Propagation predictions** depend on accurate UTC for optimal frequency selection
- **Logging transmissions** requires consistent time references across all operators

### ⏰ Why Zulu Time (UTC)?

- **Zulu Time** (military designation for UTC) is the global standard
- Eliminates confusion with local time zones
- All radio operators worldwide use the same reference
- Official frequency allocations use UTC/Zulu time

### 📅 Why Julian Date?

- **Day of Year** (3-digit Julian date) is used in:
  - Military communications
  - Aviation and maritime logs
  - Propagation analysis
  - Frequency planning documents
  - **25u programming software** often requires day-of-year input
